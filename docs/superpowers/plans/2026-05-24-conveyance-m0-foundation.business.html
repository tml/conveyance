Conveyance M0 — Milestone Overview

Foundation milestone: buildable project, the logging system, and the core file readers.

13 tasksTracked in beads (conveyance-09m)Test-driven

M0 lays the groundwork every later stage builds on. It produces a buildable, fully test-covered project with the new logging system and the readers for torrent and progress files — no downloading yet, but everything is verifiable on its own.

How progress is tracked. Work is managed in the beads issue tracker. M0 is epic conveyance-09m; the 13 tasks below are its children. Each task is test-first and closed only when the test suite is green.

What “done” looks like

zig build test passes, and running the binary emits a structured startup log line. That green test suite is the gate for starting M1, where the service comes alive and the startup improvement becomes visible to users.
