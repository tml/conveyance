Conveyance M0 — Implementation Plan (Technical)

Foundation: scaffold, non-blocking structured logging, and the pure bencode/metainfo/resume parsers.

Zig 0.14.xTDD per tasksrc/root.zig aggregates tests

M0 delivers leaf modules with no engine dependencies, each unit-tested in isolation, plus the build scaffolding. The full step-by-step code (failing test → minimal impl → verify → commit) lives in the markdown plan; this page is the structural map and task index.

Zig version. Code targets Zig 0.14.x (Task 1 installs it to a PATH shim). If the installed std/build API has drifted, the per-task zig build test step surfaces it — adapt the call site, keep the test's intent.

Conventions enforced

  • TDD: write the failing test first; never change asserted behavior to pass.
  • Allocators: parsers take an arena; string fields are zero-copy slices into the caller's input buffer, which must outlive the result.
  • No network in unit tests; fixtures live under tests/fixtures/.
  • Each task ends in a commit; a bead is claimed before coding and closed on green.
