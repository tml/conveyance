Conveyance

Project Documentation

A Zig drop-in replacement for the Transmission BitTorrent daemon.

Conveyance reimplements Transmission's core engine in Zig, packaged so the existing web UI, transmission-remote, and remote-mode GUIs work unchanged. It targets two everyday pains: the daemon's startup that blocks until every torrent has been read sequentially, and free-text logging. Each document below comes in a business-facing and a deeply-technical pass; the markdown source is the authoritative version.
